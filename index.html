Procédures d'installation

Les étapes, dans l'ordre. Clique une capture pour l'agrandir.

⚠️
Incident rencontré : la clé USB était formatée en NTFS au lieu de FAT32 : l'installateur n'arrivait pas à monter le support. Diagnostic dans le shell (cat /proc/partitions, blkid /dev/sdb1, mount /dev/sdb2 /mnt/usb). À l'avenir : laisser BalenaEtcher formater et écrire l'image.
  1. Démarrer le HP ProDesk, valider l'erreur mémoire 164 (F1), F9 pour le Boot Menu, choisir la clé USB.
  2. « Graphical install », langue Français, pays France, clavier Français.
  3. Réseau : interface eno1, nom de machine P4-C1.
  4. Mot de passe root, compte utilisateur rayan.
  5. Partitionnement assisté sur le SSD Kingston 480 Go (sda), tout dans une seule partition.
  6. Miroir ftp.fr.debian.org, pas de proxy, popularity-contest : non.
  7. Logiciels : GNOME, serveur SSH, utilitaires. Retirer la clé et redémarrer.
  8. Vérifier : IP 10.113.4.3, passerelle et DNS 10.113.10.113.
  1. Télécharger l'ISO Proxmox VE 9.2 sur proxmox.com et l'écrire sur une clé.
  2. Démarrer le serveur sur la clé : « Install Proxmox VE (Graphical) ».
  3. Pays France, fuseau Europe/Paris, clavier French ; accepter la licence.
  4. Disque cible /dev/sda (SSD Samsung 860, 931 Gio) : toutes les données sont effacées.
  5. Réseau : interface nic0, nom P4-S1.sio-turgot.local, IP 10.113.4.1/16, passerelle et DNS 10.113.10.113.
  6. Vérifier le récapitulatif, installer, redémarrer.
  7. Se connecter depuis un poste à https://10.113.4.1:8006 (P4-S2 : https://10.113.4.2:8006).
  1. Dans Proxmox : téléverser l'ISO pfSense (stockage local › ISO Images).
  2. Créer la VM avec deux cartes réseau : net0 sur vmbr0 (WAN, côté lycée) et net1 sur vmbr1 (LAN, réseau interne). Créer d'abord le pont vmbr1 sans port physique (Nœud › Système › Réseau › Créer › Linux Bridge).
  3. Installer pfSense (options par défaut), redémarrer sans l'ISO.
  4. Console : « Assign Interfaces » (WAN = vtnet0, LAN = vtnet1).
  5. « Set interface IP address » : LAN en 192.168.4.254/24 (proposition), serveur DHCP selon votre choix.
  6. Depuis une VM du LAN : interface web https://192.168.4.254, assistant de configuration, changer le mot de passe admin.

📷 Captures à ajouter (rôles, promotion, utilisateurs)
  1. Proxmox : VM « SRV-BDD » sur vmbr1, ISO Debian 13 (installation sans bureau, avec serveur SSH).
  2. IP fixe 192.168.4.20 (proposition) dans /etc/network/interfaces.
  3. Installer le serveur. Attention : Debian 13 fournit MariaDB (compatible MySQL) ; pour le vrai MySQL d'Oracle, il faut ajouter le dépôt APT de MySQL.
    sudo apt update
sudo apt install default-mysql-server   # MariaDB, compatible MySQL
sudo mysql_secure_installation
  4. Créer une base et un utilisateur :
    sudo mysql
CREATE DATABASE plot4;
CREATE USER 'app'@'192.168.4.%' IDENTIFIED BY 'motdepasse';
GRANT ALL ON plot4.* TO 'app'@'192.168.4.%';
  5. Pour les connexions à distance : bind-address = 0.0.0.0 dans la configuration, redémarrer le service, tester depuis un client.
